# California State Roleplay website

Static site with no build step and no backend. Open `index.html`, or serve the folder (for example `python3 -m http.server`).

- `index.html` is the public homepage
- `forms.html?f=<slug>` is the public forms page (staff application, appeals and others)
- `staff-dashboard/` is the staff panel. Sign-in is a demo button, and all data is sample data in `assets/staff.js` (the `DATA` object)
- `assets/styles.css` holds the shared theme
